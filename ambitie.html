Wij willen bouwen aan een gemeente waar …

Negen ambities voor Rumst, Terhagen en Reet.

✓ Wij willen bouwen aan een gemeente waar kinderen veilig kunnen opgroeien.
✓ Wij willen bouwen aan een gemeente waar jongeren kansen krijgen.
✓ Wij willen bouwen aan een gemeente waar gezinnen zich thuis voelen.
✓ Wij willen bouwen aan een gemeente waar senioren zich gewaardeerd weten.
✓ Wij willen bouwen aan een gemeente waar ondernemers alle kansen krijgen.
✓ Wij willen bouwen aan een gemeente waar verenigingen kunnen blijven groeien.
✓ Wij willen bouwen aan een gemeente waar buurten leefbaar en veilig zijn.
✓ Wij willen bouwen aan een gemeente waar duurzaamheid hand in hand gaat met gezond verstand.
✓ Wij willen bouwen aan een gemeente waar iedere inwoner zich gehoord voelt.
